# 06. Нефункциональные требования

Числа стартовые и требуют согласования с владельцем продукта.

| ID | Область | Требование | Как проверяем |
|---|---|---|---|
| NFR-1 | Корректность | Одна команда пользователя не порождает больше одной заявки при любых повторах и сбоях | Тест на повторную отправку, тест на таймаут, хаос-проверка |
| NFR-2 | Скорость | Уведомление об исполнении в пределах 5 секунд (p95) от события у брокера, пока стрим работает | Метрика задержки от события до отправки |
| NFR-3 | Скорость API | Ответ на `POST /v1/orders` не дольше 2 секунд (p95), не считая ожидания брокера сверх таймаута | Нагрузочный тест |
| NFR-4 | Надёжность | После обрыва стрима потеря событий исполнения равна нулю за счёт сверки | Тест с имитацией обрыва |
| NFR-5 | Доступность | 99,9 % для API приёма команд (допущение), мониторинг может деградировать с пометкой | Мониторинг доступности |
| NFR-6 | Восстановление | После перезапуска сервис продолжает с последнего сохранённого состояния; `SENDING` и `UNCONFIRMED` разбираются сверкой | Тест перезапуска |
| NFR-7 | Безопасность | Токен хранится в хранилище секретов в зашифрованном виде, не попадает в журналы и ответы | Ревью, автоматический поиск секретов в журналах |
| NFR-8 | Безопасность | Все соединения по TLS; доступ к заявкам только владельцу | Тесты авторизации |
| NFR-9 | Аудит | Все торговые команды и переходы состояния журналируются с временем и источником, хранятся не менее 5 лет (допущение, уточнить у комплаенса) | Проверка журнала |
| NFR-10 | Лимиты | Сервис не превышает лимиты брокера и при ошибке лимита не повторяет запросы чаще разрешённого | Тест ограничителя |
| NFR-11 | Наблюдаемость | Метрики: доля `UNCONFIRMED`, время сверки, возраст последнего события стрима, число расхождений; сквозной `requestId` | Дашборд и алерты |
| NFR-12 | Окружения | Переключение песочница/боевой режим настройкой, без изменения кода; боевой режим включается явно | Конфигурационный тест |
| NFR-13 | Время | Все времена в UTC, в интерфейсе показываются в часовом поясе пользователя | Тесты форматов |
| NFR-14 | Деньги и объёмы | Суммы и цены хранятся как десятичные значения с фиксированной точностью, не как числа с плавающей точкой | Тесты на округление |

## Алерты

| Условие | Серьёзность |
|---|---|
| Заявка в `UNCONFIRMED` дольше 60 секунд | Высокая |
| Нет событий стрима и ping дольше 30 секунд | Средняя |
| Сверка нашла расхождение | Средняя (разбор причины) |
| Доля отказов брокера выше 5 % за 5 минут | Высокая |
| Срабатывание лимита более 3 раз за минуту | Средняя |
