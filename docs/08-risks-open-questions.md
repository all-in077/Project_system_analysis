# 08. Риски, допущения и открытые вопросы

## Риски

| ID | Риск | Вероятность | Влияние | Что делаем |
|---|---|---|---|---|
| R-1 | Дубль заявки из-за повтора после таймаута | Средняя | Очень высокое (реальные деньги) | Идемпотентность, повтор только с тем же ключом, запрет нового ключа в `UNCONFIRMED` |
| R-2 | Пропущено исполнение из-за обрыва стрима | Средняя | Высокое | Сверка после переподключения и периодическая сверка |
| R-3 | Утечка токена | Низкая | Очень высокое | Хранилище секретов, токен с минимальными правами, запрет логирования |
| R-4 | Расхождение внутреннего и внешнего состояния | Средняя | Высокое | Журнал расхождений, правило «исполнение сильнее отмены», ручной разбор |
| R-5 | Превышение лимитов брокера | Средняя | Среднее | Ограничитель скорости, приоритеты, пауза по ответу брокера |
| R-6 | Изменение контракта API брокера | Средняя | Среднее | Адаптер изолирует контракт, версия контракта фиксируется, тесты на песочнице |
| R-7 | Пользователь принимает данные за актуальные | Средняя | Среднее | Пометка «данные устарели» и время последнего обновления |
| R-8 | Шум уведомлений, и пользователь перестаёт их читать | Высокая | Среднее | Агрегация, настройка каналов, только значимые события |
| R-9 | Регуляторные ограничения на хранение и обработку данных | Средняя | Высокое | Консультация с комплаенсом, минимизация данных, срок хранения как параметр |

## Допущения

| ID | Допущение | Если неверно |
|---|---|---|
| A-1 | Достаточно одного брокера и одной валюты расчётов | Нужна модель счетов и конвертации |
| A-2 | Пользователь выставляет заявки только через OrderGuard | Заявки, выставленные вручную в приложении брокера, сверка должна уметь подхватывать как внешние |
| A-3 | Один пользователь работает с одним счётом | Нужна привязка заявки к счёту, поле `account_id` |
| A-4 | Лимитные и рыночные заявки покрывают нужды MVP | Нужны стоп-заявки, см. список вне границ |
| A-5 | Допустимая задержка уведомления 5 секунд | Влияет на выбор интервала сверки и архитектуру очереди |
| A-6 | Срок хранения журналов 5 лет | Меняется после консультации с комплаенсом |
